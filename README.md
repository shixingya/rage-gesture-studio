# 😤 Rage Gesture Studio · 手势宣泄室

一个**单 HTML 文件、纯前端**的虚拟情绪发泄小游戏。调用电脑摄像头，用**手势**砸办公室物品、揍卡通老板，或切到空发泄房甩玻璃瓶、拍盘子——卡通画风、无血腥写实，只为了让你笑着把压力发泄出去。

> ⚠️ 本程序仅为虚拟趣味情绪释放工具，请勿模仿现实破坏与暴力行为。

## ✨ 特性

- **零后端 · 打开即用**：Tailwind CSS、Canvas、MediaPipe Hands 全部通过 CDN 引入，双击 `index.html` 即可运行（手势需摄像头 + 网络加载模型；无网络时鼠标交互依然完整可用）。
- **两大场景**：办公室（办公桌、电脑、键盘、水杯、文件夹、台灯、打印机、卡通老板小人）/ 空发泄房（玻璃瓶、盘子、花瓶、木板、电视、塑料桶）；墙上还有实时走针的挂钟、励志海报、沙袋等装饰。
- **对象选择**：右侧下拉框或直接点击画面中的物体，即可将其设为当前发泄目标；选中物体头顶显示名称/材质/血条标签。
- **手势识别**（MediaPipe Hands）+ **人体骨架画中画**（MediaPipe Pose）：摄像头捕捉到人后，右下角预览窗实时叠加全身骨架与手部骨骼，人动骨架跟着动；可选把骨架同步叠加到主场景。
  | 手势 | 效果 |
  | --- | --- |
  | 握拳挥拳 | 击打目标，脉冲环 + 破碎粒子 + 撞击音效；打小人后仰痛脸 |
  | 拇指食指捏合 | 抓起物体，挥出甩飞；可拖拽小人 |
  | 手掌向下猛拍 | 砸向目标，桌面抖动、物品弹飞 |
  | 手掌向前推 | 推飞目标 |
  | 双手横向横扫 | 连同周边物品一起扫落 |
  | 张开手掌靠近 | 目标害怕发抖 |
- **游戏化系统**：连击计数（带大字幕）、愤怒值进度条、充满触发**狂暴模式**（闪红 + 扫落全场）、实时分数与跨局累计破坏数。**老板小人被打够次数会“我不干了！”发火反击、飞撒文件**。物体破碎可自动重生（可关）。
- **成就系统**：8 个里程碑成就（首次摧毁、累计摧毁、连击达人、分数达人、狂暴解锁…），解锁时右上角弹框 + 音效，进度本地持久化。
- **60 秒挑战模式**：限时内随机生成落位靶标，尽可能多摧毁，结束弹成绩单（得分/摧毁/最高连击/历史最佳）。
- **灯光 / 材质面板**：强度滑块、暖/冷光切换、环境氛围光开关；可为选中物体切换塑料 / 玻璃 / 木头 / 金属 / 卡通皮肤材质，不同材质碎片、音效、可否破碎各不相同。
- **粒子 · 音效 · 屏幕震动**：碎片按材质差异化（玻璃飞溅、金属火花、木头尖刺）；受重力下落；飞体拖尾、地面阴影、损伤裂纹、暗角 vignette、破碎瞬间慢动作；Web Audio 合成音效（撞击/破碎/甩动/哀嚎/成就/狂暴低吼），可选**生成式背景氛围乐**、**连击音阶递升**，带音量滑块与全局静音，无需外部音频文件。
- **首屏引导 + 设置持久化**：首次进入展示玩法引导遮罩；音量/灵敏度/材质开关/灯光/成就/最佳成绩等全部写入 localStorage，刷新不丢。
- **手势灵敏度可调**（影响速度阈值与冷却）；**键盘 1–6 / 侧栏按钮模拟手势**，Q 键快速切场景，D 键开关调试面板（引擎/帧计数/手数/姿势/掌速/FPS）。
- **摄像头预览窗**：右下角半透明预览，可开关；手势不可用时自动降级为鼠标（或触屏）操作。
- **触屏 + 性能自适应**：Pointer Events 统一鼠标/触屏，支持拖拽甩出与双 tap 击打；实时 FPS 统计，低帧率自动降级（关粒子/阴影）；小屏顶部提示引导。

## 🎮 快速开始

直接用浏览器打开 `index.html`，或本地起一个静态服务器：

```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000/index.html
```

> ⚠️ 使用摄像头必须通过 `http://localhost` 或 `https` 访问（浏览器在非安全上下文会禁用摄像头）。首次请点击页面以解锁浏览器音频策略，并在右下角开启摄像头、授权。

## 🖱️ 无摄像头模式

即使无法使用摄像头（或模型加载失败），也可用**鼠标 / 触屏**体验全部破坏效果：
- 单击物体 = 选中；双击（双 tap）= 击打；按住拖拽后快速甩开 = 抛出破碎。
- 键盘 `1–6` 或右侧“模拟手势”按钮可一键触发六种动作；`Q` 切场景、`D` 开关调试面板。

## 🧩 代码结构

单文件内按模块组织，中文注释清晰：

1. 全局配置与状态
2. 本地持久化模块（localStorage）
3. 成就系统（里程碑检测 + 弹框）
4. 音效模块（Web Audio 合成 + 生成式背景乐）
5. 粒子动画模块（碎片/飘字/脉冲环/拖尾）
6. 场景对象模块（对象定义 + 卡通绘制 + 状态物理 + 阴影/裂纹）
7. 灯光材质模块（背景装饰 + 光照叠加 + 暗角）
8. 动作效果模块（击打/抓甩/拍/推/扫/吓 + 连击/愤怒/狂暴/重生/分数 + 老板反击）
9. 挑战模式（60 秒限时 + 动态生成靶标 + 成绩结算）
10. 手势识别模块（MediaPipe Hands + Pose 人体骨架）
11. 主渲染循环（FPS 自适应降级 + 慢动作 + 场景过渡）+ UI 绑定 + 启动

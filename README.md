# 😤 Rage Gesture Studio · 手势宣泄室

一个**单 HTML 文件、纯前端**的虚拟情绪发泄小游戏。调用电脑摄像头，用**手势**砸办公室物品、揍卡通老板，或切到空发泄房甩玻璃瓶、拍盘子——卡通画风、无血腥写实，只为了让你笑着把压力发泄出去。

> ⚠️ 本程序仅为虚拟趣味情绪释放工具，请勿模仿现实破坏与暴力行为。

## ✨ 特性

- **零后端 · 打开即用**：Tailwind CSS、Canvas、MediaPipe Hands 全部通过 CDN 引入，双击 `index.html` 即可运行（手势需摄像头 + 网络加载模型；无网络时鼠标交互依然完整可用）。
- **两大场景**：办公室（办公桌、电脑、水杯、文件夹、台灯、卡通老板小人）/ 空发泄房（玻璃瓶、盘子、木板、塑料桶）。
- **对象选择**：右侧下拉框或直接点击画面中的物体，即可将其设为当前发泄目标。
- **手势识别**（MediaPipe Hands）：
  | 手势 | 效果 |
  | --- | --- |
  | 握拳挥拳 | 击打目标，震动 + 破碎粒子 + 撞击音效；打小人后仰痛脸 |
  | 拇指食指捏合 | 抓起物体，挥出甩飞；可拖拽小人 |
  | 手掌向下猛拍 | 砸向目标，桌面抖动、物品弹飞；拍小人蹲地 |
  | 手掌向前推 | 推飞目标 |
  | 双手横向横扫 | 连同周边物品一起扫落 |
  | 张开手掌靠近 | 目标害怕发抖 |
- **灯光 / 材质面板**：强度滑块、暖/冷光切换、环境氛围光开关；可为选中物体切换塑料 / 玻璃 / 木头 / 金属 / 卡通皮肤材质，不同材质碎片、音效、可否破碎各不相同。
- **粒子 · 音效 · 屏幕震动**：碎片受重力下落自动清除；Web Audio 合成音效（撞击/破碎/甩动/哀嚎），带全局静音开关，无需外部音频文件。
- **摄像头预览窗**：右下角半透明预览，可开关；手势不可用时自动降级为鼠标操作。

## 🎮 快速开始

直接用浏览器打开 `index.html`，或本地起一个静态服务器：

```bash
python -m http.server 8790
# 浏览器访问 http://localhost:8790/index.html
```

> 首次请点击页面以解锁浏览器音频策略。使用手势需在右下角开启摄像头并授权。

## 🖱️ 无摄像头模式

即使无法使用摄像头（或模型加载失败），也可用**鼠标**体验全部破坏效果：
- 单击物体 = 选中；双击 = 击打；按住拖拽后快速甩开 = 抛出破碎。

## 🧩 代码结构

单文件内按模块组织，中文注释清晰：

1. 全局配置与状态
2. 音效模块（Web Audio 合成）
3. 粒子动画模块
4. 场景对象模块（对象定义 + 卡通绘制 + 状态物理）
5. 灯光材质模块
6. 动作效果模块
7. 手势识别模块（MediaPipe Hands）
8. 主渲染循环 + UI 绑定 + 启动

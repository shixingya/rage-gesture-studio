## 1. 产品概述

### 1.1 一句话价值主张
用一个"打开即砸、不用负责、随时随地"的虚拟发泄空间，让都市人**在 30 秒到 5 分钟内**把压力安全地宣泄出去。

### 1.2 目标用户与场景
- **打工人**：被甲方/会议/DDL 逼到崩溃，需要即时出气口。
- **学生**：考试、人际压力，想找个不打扰他人的出口。
- **情绪易波动人群**：需要一个"安全容器"承接愤怒、焦虑、挫败。
- 典型场景：加班深夜、被批评后、通勤路上（手机）、午休碎片时间。

### 1.3 核心矛盾（要解决的痛点）
线下宣泄室：**贵、要出门、有安全门槛、不隐私、不可高频**。
本产品：**免费、零门槛、隐私（数据不出本机）、可高频、跨设备（电脑/手机）**，用虚拟破坏 + 手势/鼠标/触屏还原线下宣泄的"爽感"。

## 3. 功能需求（对齐全景图，按优先级）

### 3.0 已实现能力盘点（v1 基线）
- **双场景**：办公室 / 空发泄房，含实时挂钟、海报、沙袋等装饰。
- **对象系统**：电脑/键盘/水杯/台灯/打印机/花瓶/玻璃瓶/盘子/木板/电视/塑料桶/老板小人 + 基础桌面。
- **6 种破坏动作**：出拳、抓取甩出、下拍、前推、横扫、吓唬；三种输入统一（手势/鼠标/触屏）。
- **手势识别**：MediaPipe Hands 姿态保持式触发 + Pose 人体骨架画中画，可叠加主场景。
- **游戏化**：连击、愤怒值、狂暴模式、分数、分数里程碑彩带、8 项成就、5 项每日目标、60 秒挑战 + 本地排行榜 Top5。
- **表现层**：材质差异化碎片、慢动作、拖尾、地面阴影、损伤裂纹、暗角、屏幕震动、打击白闪/挤压脉冲、Web Audio 合成音效、生成式背景乐。
- **系统**：localStorage 全量持久化、首屏引导、全局帮助浮层、Q/D/? 快捷键、FPS 自适应降级、无障碍（减少动态/高对比）。

### 3.1 P1 — 近期重点（补齐"声音 + 代入 + 轻解压"三大市面热门）

**F1 呐喊分贝玩法（麦克风）** 🔲
- 用户对着麦克风大喊，实时读取分贝 → 分数/震碎玻璃/狂暴加速。
- 交互：新增"🎤 呐喊"模式；画面有分贝仪表；达到阈值触发全场玻璃碎裂特效。
- 技术：`getUserMedia(audio)` + `AnalyserNode` 求 RMS→dB；需 localhost/https 授权；无权限时降级隐藏该玩法。
- 隐私：仅本地实时分析，**绝不录音上传**，页面明示。

**F2 自定义出气对象（贴标签）** 🔲
- 允许给物体输入文字标签（如"甲方需求""DDL""前任"），砸的时候带标签飞出/碎裂，强化代入感。
- 复用现有 `name` 字段 + 一个输入框；破碎时把标签作为 floater 抛出。

**F3 气泡膜解压模式** 🔲
- 一屏"气泡膜"，逐个点击"啪"爆破 + ASMR 音效，可无限重置；作为"温和关卡"与暴烈发泄并存。
- 纯鼠标/触屏即可完成，实现成本低，留存拉新友好。

### 3.2 P2 — 中期扩展（涂鸦 / 主题 / 情感收尾）

- **F4 涂鸦/喷漆模式** 🔲：Canvas 手绘，可选颜色/笔刷，"泼颜料"发泄，支持清空。
- **F5 撕纸玩法** 🔲：拖动撕裂动画 + 碎裂粒子 + 撕纸音效。
- **F6 新增主题房/对象** 🔲：卧室（闹钟、盆栽、椅子、拖鞋）、手机屋（砸手机）等，扩充 SHAPES 与场景皮肤。
- **F7 情绪收尾·呼吸放松** 🔲：宣泄后进入 1 分钟呼吸引导（缩放圆 + 舒缓音），把用户从"高唤醒"带回平静，形成体验闭环。
- **F8 分享成绩卡** 🔲：把本局分数/连击/成就生成图片卡（canvas.toDataURL）本地下载，社交传播。

### 3.3 持续项 — 深度与留存
- 每日目标库扩充、赛季/连续签到、成就墙、手势新动作（如"比心"温柔模式做反差）。
- 无障碍与本地化（多语言）、手柄/体感（远期，超出媒介）。

## 4. 非功能需求
- **零后端 · 打开即用**：全部依赖 CDN，单 `index.html`；离线时鼠标/触屏玩法完整可用。
- **性能**：实时 FPS 监测，低于阈值自动降级（关粒子/阴影）；粒子/物体数量上限。
- **兼容性**：桌面 Chrome/Edge/Firefox、移动端浏览器；窄屏横屏引导。
- **无障碍**：尊重 `prefers-reduced-motion`；减少动态 + 高对比开关；键盘可达。
- **隐私**：摄像头/麦克风**本地实时处理、不上传、不存储**；所有进度仅存 `localStorage`（键 `rage_gesture_studio_v1`），用户可一键清除。
- **健壮性**：MediaPipe 模型加载失败不阻断（降级）；手势与鼠标共用动作层；Web Audio 首交互解锁。

## 5. 体验与交互原则
1. **即时爽感**：任意一次命中都要有视觉（粒子/白闪/震动）+ 听觉（音效）双反馈。
2. **低门槛**：姿态保持式触发、就近自动锁定目标、无摄像头也能全功能。
3. **情绪曲线**：宣泄（暴烈）→ 成就/庆祝（高峰）→ 可选放松收尾（回落），避免"越玩越上头"。
4. **幽默消解暴力**：卡通老板"我不干了"、哀嚎、飞文件等滑稽元素，弱化攻击性。
5. **安全边界**：固定免责声明、无写实血腥、无真人形象攻击引导。

## 6. 数据与度量
- **北极星指标**：单次会话"有效宣泄时长"（有连续命中行为的活跃秒数）。
- 激活：首屏引导完成 → 首次破坏的转化率。
- 参与：人均连击峰值、狂暴触发率、每日目标完成率、挑战参与率与重玩率。
- 留存：次日/7 日回访、跨天连续游玩天数。
- 传播：成绩卡分享次数（F8 上线后）。
- 埋点原则：全部本地统计，不上传个人数据；如需匿名聚合需另行合规评估。

## 7. 技术约束与架构（现状）
单文件内按模块组织：全局状态 → 本地持久化 → 成就 → 音效（Web Audio 合成）→ 粒子 → 场景对象（`makeObj/buildOffice/buildRoom/SHAPES` 卡通绘制）→ 灯光材质主题 → 动作效果（`actHit/Grab/Throw/Slap/Push/Sweep/Scare`）→ 手势识别（`analyzeHands` 21 点启发式）→ 挑战/每日目标 → 主循环 + UI。
新增玩法沿用"**动作层统一、输入层多路**"的模式（手势/鼠标/触屏/未来麦克风/涂鸦都调同一批 `act*`/特效函数），保证一致性与可维护性。

## 9. 风险与应对
- **媒介限制**：线下"触觉/力量"体验无法 1:1 复刻 → 用代入感（标签、老板小人）、节奏（连击/狂暴/庆祝）与多感官（音效 + 未来麦克风）补偿。
- **麦克风/摄像头授权门槛** → 渐进增强，拒绝授权时优雅隐藏对应玩法，核心不依赖。
- **情绪导向**：纯破坏是否强化攻击性 → 用幽默卡通化 + 放松收尾 + 免责声明平衡，定位为"轻量解压"而非暴力模拟。
- **留存难**：单一玩法易腻 → 每日目标 + 挑战排行 + 新玩法轮换驱动回访。
- **网络依赖**：手势/人体模型走 CDN → 保留鼠标降级与离线可用。

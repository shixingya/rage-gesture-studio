## 它是什么

《手势宣泄室》是一个**单个网页文件、纯前端、零后端**的小游戏：调用电脑摄像头，用**手势**把办公室物品砸个稀烂、揍卡通老板出气，或切到空发泄房甩玻璃瓶、拍盘子。没有摄像头时，用**鼠标 / 触屏 / 键盘**一样可以发泄。

- 🎯 双场景：办公室 & 空发泄房
- 👊 6 种手势 + 6 种破坏动作
- 🎮 连击、愤怒值、狂暴模式、分数、成就、每日目标、限时挑战
- 🪩 主题皮肤（白天 / 夜晚 / 迪斯科）、材质系统、生成式背景乐
- ♿ 无障碍（减少动态、高对比）与自动性能降级

## 准备工作与打开方式

### 方式 A：直接双击（最快，但没有摄像头手势）

用浏览器直接打开 `index.html` 即可。**注意**：浏览器在 `file://`（双击打开）协议下**会禁用摄像头**，此时只能用鼠标/触屏/键盘玩法。想用手势识别请使用方法 B。

### 方式 B：本地服务器（推荐，解锁摄像头）

在项目文件夹打开终端（PowerShell），运行：

```bash
python -m http.server 8000
```

然后用浏览器访问：

```
http://localhost:8000/index.html
```

> 只有通过 `http://localhost` 或 `https` 访问，浏览器才允许调用摄像头（这是浏览器的安全策略，非本程序限制）。

### 首次进入

1. 页面会弹出**欢迎引导遮罩**，简单介绍玩法；点 **🚀 开始发泄** 进入。
2. 勾选 **下次不再显示** 可跳过以后每次的引导。
3. 若要用摄像头：在右侧面板点 **📷 摄像头 → 开启**，并在浏览器弹窗里**授权**使用摄像头。右下角会出现画中画预览窗。
4. 首次点击页面任意处会解锁浏览器音频（浏览器要求声音必须由用户交互触发）。

## 三种玩法：手势 / 鼠标 / 触屏

> 三种输入最终都调用同一套动作，效果完全一致。没有摄像头也能玩个痛快。

### 🖱️ 鼠标

| 操作 | 效果 |
| --- | --- |
| 单击物体 | 选中该物体为当前目标 |
| 双击物体 | 击打目标 |
| 按住拖拽后快速甩开 | 抓起并抛出，落地破碎 |
| 点击空白处 | 取消选中 |

### 📱 触屏

| 操作 | 效果 |
| --- | --- |
| 点按物体 | 选中 |
| 快速双击（双 tap） | 击打 |
| 按住拖拽后甩出 | 抛出破碎 |

### 👊 手势（需开启摄像头 + 联网加载模型）

摄像头捕捉到人后，右下角预览窗会实时叠加**全身骨架 + 手部骨骼**，你动它也跟着动。张开手掌在画面移动，主舞台上会出现一个橙色手形光标跟随。

| 手势 | 动作 | 效果 |
| --- | --- | --- |
| 握拳并挥动（或保持握拳） | 出拳 | 反复击打最近/选中目标 |
| 拇指 + 食指捏合 | 抓取 | 抓起物体，松手甩飞 |
| 张开手掌向下猛拍 | 下拍 | 砸向目标，桌面抖动、物品弹飞 |
| 手掌朝镜头快速前推 | 前推 | 推飞目标 |
| 双手快速横向横扫 | 横扫 | 扫落同一水平带的多个物品 |
| 张开手掌缓慢靠近 | 吓唬 | 目标害怕发抖 |

> 手势触发**不是瞬时判定**：出拳、吓唬采用「姿态保持式」——保持手势就会按固定间隔连续触发，无需快速挥动，门槛更低。若手势始终不触发，见 [故障排查](#故障排查)。

## 游戏化系统（连击 / 愤怒 / 狂暴 / 分数）

- **连击 Combo**：每次命中累加，顶部 `连击：xN` 实时显示；屏幕中部会出现「xN」大字幕。**2.5 秒内没有新命中，连击自动清零**。连击越高，击打音效的音阶越高（成就感递升）。
- **愤怒值 Rage**：顶部 🔥 进度条，每次攻击积累愤怒值。
- **狂暴模式 Berserk**：愤怒值充满（100%）自动触发——屏幕闪红、低吼音效、一次性扫落全场可碎物，是最高潮的宣泄时刻。
- **分数 Score**：每次命中与摧毁都加分，分数随连击倍率放大。顶部 `分数：N` 显示本局分数。
- **分数里程碑庆祝**：本局得分首次跨越 **500 / 1000 / 2000 / 5000 / 1万 / 2万 / 5万** 时，自动撒落彩色纸屑 + 弹框 + 音效。
- **老板反击**：卡通老板小人被打够一定次数，会「我不干了！」发火，并往屏幕上飞撒文件（纯视觉效果）。
- **物体重生**：被摧毁的物体会在约 1.6 秒后原地重生，可一直玩下去。若不喜欢，可在右侧「玩法」里关掉 **物体自动重生**。

## 成就 · 每日目标 · 60 秒挑战

### 🏅 成就系统（共 8 个里程碑）

| 成就 | 达成条件 |
| --- | --- |
| 初试身手 | 首次摧毁物体 |
| 拆家新手 | 累计摧毁 20 个 |
| 破坏之王 | 累计摧毁 100 个 |
| 连击达人 | 达成 10 连击 |
| 无敌连招 | 达成 30 连击 |
| 小有所成 | 本局得分达 1000 |
| 宣泄大师 | 本局得分达 5000 |
| 理性崩塌 | 首次进入狂暴模式 |

解锁时右上角弹框 + 音效。点右侧「成就：已解锁 N/8」旁的 **查看** 可列出全部成就。

### 📋 每日目标（每天自动刷新，跨天重置）

右侧「今日目标」面板列出 5 个小任务，完成打钩、带进度条：

| 目标 | 条件 |
| --- | --- |
| 摧毁 15 个 | 当天累计摧毁 15 个物体 |
| 达成 12 连击 | 当天最高连击达到 12 |
| 累计 2000 分 | 当天累计得分达 2000 |
| 切换 3 次场景 | 当天主动切场景 3 次 |
| 进入狂暴 1 次 | 当天触发一次狂暴模式 |

每天第一次打开会自动换成新的一天；当天进度会保存，刷新不丢。

### ⏱ 60 秒挑战模式 + 🏅 本地排行榜

点右侧 **⏱ 开始 60 秒挑战**：屏幕中央出现倒计时与实时得分，场上会不断随机生成落位靶标，尽可能多地摧毁。60 秒结束弹出**成绩单**（本局得分 / 摧毁数量 / 最高连击 / 历史最佳）。

- 每次挑战成绩（>0 分）会自动写入**本地排行榜 Top5**（含成绩、摧毁、连击、日期）。
- 点 **🏅 排行榜 Top5** 随时查看。
- 挑战成绩与排行榜均保存在本地浏览器。

## 场景与主题皮肤

### 两大场景

- **🏢 办公室**：办公桌（固定不可打碎）、电脑、键盘、台灯、水杯、文件夹、打印机、卡通老板小人；墙上是有实时走针挂钟、励志海报的办公室。

## 灯光 · 材质 · 音效

### 💡 灯光设置
- **强度滑块**：控制画面整体明暗。
- **暖光 / 冷光**：切换色温。
- **环境氛围光**：开关顶部光晕。
- **主题皮肤**：见上一节。

### 🧪 材质设置（作用于当前选中物体）
可为选中物体切换材质，不同材质的**碎片、音效、能否破碎**各不相同：

| 材质 | 特征 |
| --- | --- |
| 塑料 | 常规碎片 |
| 玻璃 | 半透明 + 飞溅碎片 + 清脆碎裂音；破碎时慢动作 |
| 木头 | 尖刺木屑 + 闷响 |
| 金属 | 火花 + 金属音；破碎时慢动作 |
| 卡通皮肤 | 仅限老板小人，不可打碎，只会被打得龇牙 |

> 小人只能用「卡通皮肤」，其它物体不能设成皮肤。

### 🔊 音效
- **音量滑块** + **全局静音**开关。
- 所有音效均由 Web Audio **实时合成**（撞击 / 破碎 / 甩动 / 哀嚎 / 成就 / 狂暴低吼），**无需任何外部音频文件**，离线也能响。
- **背景氛围乐**：勾选后播放生成式低音 + 分解和弦循环，可随开随关。

## 无障碍设置

右侧 **♿ 无障碍** 面板提供两个开关（均会记住）：

- **减少动态**：关闭屏幕震动、破碎慢动作、环境漂浮粒子、迪斯科光束动画、狂暴闪烁脉动，并大幅减少彩带粒子数量。首次打开时，程序会**自动读取你系统的「减少动态效果」偏好**（`prefers-reduced-motion`）默认开启此项。
- **高对比模式**：去掉画面压暗与暗角（vignette），保证内容明亮清晰。

此外，程序会**实时监测帧率（FPS）**：帧率过低时自动进入降级（关闭粒子与阴影），恢复正常后自动解除，无需手动干预。

## 数据、隐私与本地存储

- **完全本地运行**：所有逻辑都在你的浏览器里，不上传任何数据，没有账号、没有服务器。
- **摄像头画面不出本机**：手势识别在你的设备上本地完成，视频流不发送到任何地方。
- **持久化**：设置、成就、累计破坏数、最佳连击、每日目标进度、主题、排行榜成绩等，全部写入浏览器 `localStorage`（键名 `rage_gesture_studio_v1`）。刷新/关闭后再打开都会保留。

### 想清空数据？
在浏览器开发者工具 Console 执行：

```js
localStorage.removeItem('rage_gesture_studio_v1'); location.reload();
```

或直接用右侧 **🔄 重置场景** 按钮（会恢复物体、清零本局连击/分数/破坏计数，但不清除跨局成就与排行榜）。

## 常见问题 FAQ

**Q：点「开启」摄像头没反应 / 提示需要 localhost？**
A：双击 `index.html`（`file://`）时浏览器禁用摄像头。请用 `python -m http.server 8000` 起本地服务，访问 `http://localhost:8000/index.html`，并在浏览器弹窗中授权。

**Q：手势开启后一直显示「模型下载中…」或「加载失败」？**
A：手势模型（MediaPipe）需从 CDN 联网下载。请确认网络可访问 `cdn.jsdelivr.net`；加载失败时仍可用鼠标/触屏/键盘 1-6 全部功能。

**Q：识别到了手但动作不触发？**
A：① 先在右侧拉高「手势灵敏度」；② 出拳请用「握拳」并稍作停顿（姿态保持式会自动连打）；③ 打开调试面板（按 `D`）看「手 / 指伸 / 掌心 / 目标」数值是否正常。

**Q：没有声音？**
A：浏览器要求音频需由用户交互解锁——请先点击一次页面；再检查是否静音、音量是否为 0。

**Q：画面很卡？**
A：程序会自动降级；你也可以在「灯光设置」关环境氛围光、或开启「♿ 减少动态」进一步减负。

**Q：手机上能玩吗？**
A：可以，用手机浏览器打开并横屏更舒适，直接用拖拽 / 双击发泄；顶部会有一条小屏提示。

## 故障排查

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 摄像头无法开启 | `file://` 打开 / 未授权 / 无 https | 改用 `http://localhost:8000`；地址栏允许摄像头 |
| 预览窗黑屏 | 模型未加载 / 网络受限 | 用鼠标降级；检查网络后刷新重试 |
| 手势能显示但无动作 | 灵敏度过低 / 判定门槛 | 拉高灵敏度；保持手势姿势；按 `D` 看调试数值 |
| 无音效 | 未交互解锁音频 / 静音 | 先点一下页面；检查音量与静音开关 |
| 想复位一切 | — | 用 `localStorage.removeItem('rage_gesture_studio_v1')` 后刷新 |
| 调试面板信息 | 定位手势问题用 | 按 `D` 开关；含引擎状态/帧数/手数/姿势/掌速/FPS |

> 需要远程协助定位手势问题时：开启摄像头 → 按 `D` 显示调试面板 → 截图左下角面板数值反馈即可。
